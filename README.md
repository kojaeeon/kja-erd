# KJA ERD

로컬에서 실행하는 개인용 ERD 편집기입니다. React + React Flow + Vite, Node.js, SQLite로 구성됩니다.

## 설치 및 실행

Node.js **24.10 이상**이 필요합니다.

```powershell
npm install
npm run dev
```

브라우저에서 http://127.0.0.1:3000 으로 접속합니다. 서버는 로컬 주소에만 바인딩합니다.

```powershell
npm run build  # 배포 빌드
npm start      # 배포 실행
npm test       # 테스트
```

## 주요 기능

- **ERD 편집**: 테이블·컬럼·PK/FK·인덱스·메모, 컬럼 순서 변경, 관계 설명·선 스타일, 검색·미니맵·다크 모드.
- **SQL 메모**: 메모 선택 후 테두리·모서리 드래그로 크기 조절, SQL 구문 강조·줄 번호·들여쓰기, 헤더 복사 아이콘으로 SQL 전체 복사. 크기와 내용은 자동 저장됩니다.
- **프로젝트 관리**: 자동 저장, 최근 30개 저장 이력 복원, 복사·휴지통·복원, JSON 가져오기·내보내기.
- **사전 관리**: 프로젝트·공용 단어/용어/타입 사전, 자동완성, 연결 컬럼 동기화.
- **SQL**: DB2(기본)·SQLite·MySQL·PostgreSQL DDL 출력, DB2 DDL 분석 및 SQLite 메타데이터 가져오기, 테이블별 SQL 예시.
- **코드·데이터 생성**: Java VO, MyBatis Mapper XML, 테스트 INSERT SQL, XLSX → INSERT 변환.
- **테이블 OUT**: 테이블 메뉴 **OUT…**의 SQL·VO·MD·Excel·SQL XML 탭에서 해당 테이블을 출력합니다. 탭을 이동해도 편집 내용과 옵션을 유지합니다. SQL XML 탭은 resultMap XML·resultMap 없는 쿼리 XML·순수 SQL 출력을 선택하며 SELECT 논리명 주석을 지원합니다. 순수 SQL의 `:필드명` 변수는 실행 환경에 맞춰 바인딩합니다. SQL은 테이블·컬럼 논리명을 `/* 논리명 */` 주석으로, VO는 논리명을 Javadoc으로 출력합니다.
- **Markdown 정의서**: 상단 **MD OUT → 헤더 컬럼 설정**에서 논리명·컬럼명·카멜케이스·타입·PK/FK·NULL·기본값·설명 등의 출력 항목을 프로젝트에 저장하고, **전체 OUT**으로 모든 테이블을 내보냅니다. 개별 테이블은 **OUT… → MD**에서 표 미리보기·MD 소스·복사·`.md` 다운로드를 사용합니다.
- **Excel 정의서**: 상단 **Excel OUT**은 전체 테이블, **OUT… → Excel**은 해당 테이블을 `테이블 정의서` 한 시트에 컬럼당 한 행으로 출력합니다. 테이블 정보·키·인덱스·컬럼 정의·참조 컬럼을 함께 제공하며 헤더 색상 설정, `.xlsx` 다운로드, Excel 붙여넣기용 클립보드 복사를 지원합니다.
- **스키마명 변경**: ERD 테이블 헤더, Excel 정의서의 스키마 셀 또는 MD 정의서 미리보기의 스키마명을 클릭해 수정합니다. Enter 또는 다른 곳 클릭으로 적용하고 Esc로 취소합니다. 빈 값으로 스키마를 제거할 수 있으며, 같은 스키마 안의 테이블명 중복은 차단합니다. 변경은 프로젝트에 저장되고 SQL·참조 컬럼·정의서 출력에 함께 반영됩니다.
- **내보내기**: 현재 화면 PNG, JSON, 헤더 색상 설정.

## 기본 사용법

테이블 추가 → 컬럼 편집 → 부모 컬럼의 오른쪽 연결점을 자식 컬럼의 왼쪽 연결점으로 연결합니다. 관계선을 클릭하면 설명과 스타일을 수정할 수 있습니다.

상단 SQL 메뉴에서 전체 DDL 출력·SQL 가져오기·SQLite 메타 조회를, 테이블 메뉴에서 개별 SQL·VO·Mapper XML·테스트 데이터 생성을 실행합니다. SQL OUT의 **FK 생성문 포함**은 기본적으로 꺼져 있습니다.

메모는 헤더를 잡아 이동하며 편집 영역은 SQL 선택·입력·스크롤에 사용합니다. 기존 메모의 내용은 유지됩니다. SQL 편집기에서 `Tab / Shift+Tab`은 들여쓰기·내어쓰기, `Ctrl+Z / Ctrl+Y`는 코드 편집 취소·재실행입니다. 크기 변경은 캔버스에서 실행 취소할 수 있습니다. 복사 아이콘은 줄 번호를 제외한 SQL 원문만 복사하며, 클립보드 API를 사용할 수 없으면 기본 복사를 시도합니다.

단축키: `Ctrl+S` 저장, `Ctrl+Z / Ctrl+Y` 실행 취소·재실행, `Ctrl+F` 검색, `F3 / Shift+F3` 다음·이전 결과.

## 저장 및 백업

설계·저장 이력·공용 사전은 `data/erd.sqlite`에 저장하며 브라우저 초안은 localStorage에 보관합니다. 변경 후 1.2초 뒤 자동 저장됩니다. 프로젝트 전환 전 저장 완료를 확인하고, 업데이트 시 기존 `data` 폴더를 유지하세요.

## SQLite 메타데이터 관리

`data/erd.sqlite`의 `metadata_tables`(테이블 목록), `metadata_columns`(컬럼 목록)에 테이블과 컬럼 정의를 저장합니다. 앱 시작 시 빈 저장용 테이블을 자동 생성합니다.

- ERD 테이블의 **메뉴 → SQLite 메타데이터에 등록**에서 테이블과 컬럼을 저장합니다. 같은 스키마와 이름이 등록되어 있으면 관리 화면에서 수정하세요.
- **SQL → SQLite 메타데이터 관리**에서 스키마·테이블명/논리명으로 조회하고, 정의와 컬럼을 수정하거나 삭제합니다. 변경은 메타데이터 카탈로그에 적용됩니다.
- **SQL → SQLite 메타데이터 가져오기**에서 원하는 테이블을 체크하고 미리보기 확인 후 ERD에 적용합니다. 중복은 건너뛰기·갱신·이름 변경을 선택합니다.

DBeaver 등 외부 도구에서도 SQLite 파일에 직접 입력할 수 있습니다. 메타데이터에는 테이블과 컬럼 속성을 저장하며, 관계선과 인덱스는 ERD에서 관리합니다.

- [상세 입력 가이드](docs/sqlite-metadata-guide.md): 모든 필드 규칙·최소 INSERT·수정/삭제·주의사항
- [저장용 테이블 생성 SQL](src/metadata-schema.sql)
- [고객 / 정기점검 INSERT 예제](docs/metadata-example.sql)

화면에서도 생성 SQL·INSERT 예제·가이드를 다운로드할 수 있습니다. DB2 JDBC 연결·Java·드라이버 설정은 제거했습니다. DB2 SQL 출력과 SQL 가져오기는 계속 지원합니다.

## 제한 사항

- DB2는 **Db2 LUW 11.5** 기준입니다. 생성 SQL과 MyBatis 코드는 실제 사용 환경에서 검증하세요.
- SQL 실행은 별도 SQLite 파일의 테이블·인덱스 생성만 지원합니다. DB2·MySQL·PostgreSQL은 SQL 출력만 지원합니다.
- ERD 관계 가져오기는 단일 컬럼 FK만 지원합니다. 복합 FK·표현식 인덱스 가져오기, 전체 캔버스 PDF, 수동 관계선 꺾임 편집은 지원하지 않습니다.

### DB2 메타데이터 스크립트 확인

`docs/db2_to_kja_erd.py`는 JDBC 원본 컬럼명(`TABSCHEMA`, `TABNAME` 등)을 표준 필드명으로 매핑하고 Java 문자열을 Python 문자열로 변환합니다. 필수 컬럼이 누락되면 실제 조회 컬럼명을 오류 메시지에 표시합니다. 사용자 JDBC 래퍼는 계산 컬럼의 `AS` 별칭을 보존하도록 `ResultSetMetaData.getColumnLabel()`을 사용하세요.

```bash
python -m unittest discover -s tests -p 'test_*.py'
```
