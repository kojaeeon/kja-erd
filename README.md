# KJA ERD

로컬에서 실행하는 개인용 ERD 편집기입니다. React + React Flow + Vite, Node.js, SQLite로 구성됩니다.

## 설치 및 실행

Node.js **24.10 이상**이 필요합니다.

```powershell
npm install
npm run dev
```

브라우저에서 http://127.0.0.1:3000 으로 접속합니다. 서버는 로컬 주소에만 바인딩합니다.

```powershell
npm run build  # 배포 빌드
npm start      # 배포 실행
npm test       # 테스트
```

## 주요 기능

- **ERD 편집**: 테이블·컬럼·PK/FK·인덱스·메모, 컬럼 순서 변경, 관계 설명·선 스타일, 검색·미니맵·다크 모드.
- **SQL 메모**: 메모 선택 후 테두리·모서리 드래그로 크기 조절, SQL 구문 강조·줄 번호·들여쓰기, 헤더 복사 아이콘으로 SQL 전체 복사. 크기와 내용은 자동 저장됩니다.
- **프로젝트 관리**: 자동 저장, 최근 30개 저장 이력 복원, 복사·휴지통·복원, JSON 가져오기·내보내기.
- **사전 관리**: 프로젝트·공용 단어/용어/타입 사전, 자동완성, 연결 컬럼 동기화.
- **SQL**: DB2(기본)·SQLite·MySQL·PostgreSQL DDL 출력, DB2 DDL 분석 및 JDBC 메타 가져오기, 테이블별 SQL 예시.
- **코드·데이터 생성**: Java VO, MyBatis Mapper XML, 테스트 INSERT SQL, XLSX → INSERT 변환.
- **내보내기**: Excel 테이블 정의서·사전, 현재 화면 PNG, 헤더 색상 설정.

## 기본 사용법

테이블 추가 → 컬럼 편집 → 부모 컬럼의 오른쪽 연결점을 자식 컬럼의 왼쪽 연결점으로 연결합니다. 관계선을 클릭하면 설명과 스타일을 수정할 수 있습니다.

상단 SQL 메뉴에서 전체 DDL 출력·SQL 가져오기·DB2 메타 조회를, 테이블 메뉴에서 개별 SQL·VO·Mapper XML·테스트 데이터 생성을 실행합니다. SQL OUT의 **FK 생성문 포함**은 기본적으로 꺼져 있습니다.

메모는 헤더를 잡아 이동하며 편집 영역은 SQL 선택·입력·스크롤에 사용합니다. 기존 메모의 내용은 유지됩니다. SQL 편집기에서 `Tab / Shift+Tab`은 들여쓰기·내어쓰기, `Ctrl+Z / Ctrl+Y`는 코드 편집 취소·재실행입니다. 크기 변경은 캔버스에서 실행 취소할 수 있습니다. 복사 아이콘은 줄 번호를 제외한 SQL 원문만 복사하며, 클립보드 API를 사용할 수 없으면 기본 복사를 시도합니다.

단축키: `Ctrl+S` 저장, `Ctrl+Z / Ctrl+Y` 실행 취소·재실행, `Ctrl+F` 검색, `F3 / Shift+F3` 다음·이전 결과.

## 저장 및 백업

설계·저장 이력·공용 사전은 `data/erd.sqlite`에 저장하며 브라우저 초안은 localStorage에 보관합니다. 변경 후 1.2초 뒤 자동 저장됩니다. 프로젝트 전환 전 저장 완료를 확인하고, 업데이트 시 기존 `data` 폴더를 유지하세요.

## DB2 JDBC 설정

앱 서버에 **Java 17 이상**과 IBM `db2jcc4.jar`를 준비합니다.

- 드라이버 기본 경로: `drivers/db2jcc4.jar`
- 경로 변경: `DB2_JDBC_JAR` 환경변수 또는 화면의 절대 경로
- Java 실행 파일 지정: `JAVA_BIN`

SQL 메뉴의 DB2 JDBC 메타 가져오기에서 JDBC 주소·계정·비밀번호·스키마를 입력합니다. 서버의 DB2 접근과 메타 조회 권한이 필요하며, 계정·비밀번호는 저장하지 않습니다.

## 제한 사항

- DB2는 **Db2 LUW 11.5** 기준입니다. 생성 SQL과 MyBatis 코드는 실제 사용 환경에서 검증하세요.
- SQL 실행은 별도 SQLite 파일의 테이블·인덱스 생성만 지원합니다. DB2·MySQL·PostgreSQL은 SQL 출력만 지원합니다.
- ERD 관계 가져오기는 단일 컬럼 FK만 지원합니다. 복합 FK·표현식 인덱스 가져오기, 전체 캔버스 PDF, 수동 관계선 꺾임 편집은 지원하지 않습니다.
